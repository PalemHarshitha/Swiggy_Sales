The dataset represents **real-world** **Swiggy food delivery sales** data used for Excel-based analysis and dashboard creation.

Columns Included:

Order_ID – Unique identifier for each order

Order_Date – Date when the order was placed

Customer_Name – Name of the customer

City – City where the order was delivered

Restaurant_Name – Restaurant fulfilling the order

Food_Category – Type of food ordered (Biryani, Pizza, Burgers, etc.)

Order_Amount – Total value of the order

Delivery_Fee – Delivery charge applied

Payment_Mode – UPI, Card, Cash, Wallet

Order_Status – Delivered / Cancelled / Pending

Data Size:

Records: 5,000+ rows (simulated real-world data)

Time Period: Multiple months

Data Type:

Structured tabular data suitable for:

Pivot Tables

Pivot Charts

Dashboards

Power Query cleaning
